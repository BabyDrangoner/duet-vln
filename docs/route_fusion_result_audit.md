# R0：实际首跳融合诊断结果

2026-10-03。结论：**当前证据不支持进入该融合方案的训练。** 固定训练场景轨迹上，实际首跳分数几乎不改变决定，唯一改变的开发状态代价更高。

## 数据与一致性

预先固定的五种规则见 `configs/route_fusion_diagnostic.json`；结果为 `outputs/study-20261003/r0-route-fusion.json`。本次仅 CPU 重算已有 D1 训练场景数据，没有新增官方验证访问、拟合或导航 rollout。

- train_fit：193 个回合、49 个房屋、1,139 个有效决策。
- train_dev：96 个回合、12 个房屋、598 个有效决策；另 1 个强制结束状态只用于描述统计。
- 两组全部图距离及原融合 logits 重建误差均为 0；分别核对 946、503 条实际执行路径。
- 初次运行因 MatterSim 的 float32 坐标语义不一致而中止；修复坐标转换后重跑。没有改变样本、规则或一致性门槛，失败日志与修复记录保留。

## 机会覆盖

| 集合 | 有远端候选 | 已访局部邻居 ≥2 | 远端首跳组 ≥2 | 原策略选远端 |
|---|---:|---:|---:|---:|
| train_fit | 880 | 11 | 6 | 1 |
| train_dev | 469 | 17 | 14 | 6 |

虽然远端候选常存在，多路回走竞争及实际采用远端目标的事件很少。不能把“远端候选出现率”当成方法的有效作用覆盖率。

## 固定状态干预

表中 Δ 表示相对原融合的平均 execution regret 变化，单位米，**正值更差**。仅在双方选择代价有限的配对状态中计算，不能转换为完整导航 SR/SPL。

| 规则 | fit 改变次数 | fit Δ | dev 改变次数 | dev Δ |
|---|---:|---:|---:|---:|
| 实际首跳局部分数 | 0 | 0 | 1 | +0.008435 |
| 回走分数均值 | 0 | 0 | 0 | 0 |
| 回走分数 logsumexp | 0 | 0 | 3 | +0.040192 |
| HSPR 对应远端 2g 分数 | 18 | +0.151214 | 20 | +0.227196 |

首跳规则在 dev 的唯一变化将本已非最优的动作换为更差动作，配对代价总增量 5.002213 米；因此严格“最优→非最优”的 damage 计数仍为 0。只看 fixes/damages 会漏掉这种退化。按房屋等权的 execution Δ 为 +0.007719 米，方向一致。

dev 的 logsumexp 规则损害 2 个原最优决定，未修复最优性；2g 规则损害 16 个原最优决定，并使 2 个原非有限代价选择变为有限。报告保留这些非有限转换，不能仅用有限均值概括全部影响。

固定 ±1 公共局部分数平移时，原融合在 dev 改变 2/3 个 argmax；首跳、均值与 logsumexp 不改变。数学上的公共平移性质得到核对，但这不证明实际训练得到的公共分数偏移导致自然导航错误。

## 研究决定与边界

停止本轮“直接用首跳局部分数替换共享回走和”的候选，不扩展官方验证搜索或直接包装成论文方法。

这不是所有路径建模方法无效的结论。D1 的房屋被原始 DUET 训练见过，原决策很强，远端错误覆盖有限；尚未测试重新学习路由表示的模型。HSPR 对照只是将其对应视觉融合规则套用到固定 DUET 分数，**没有复现 HSPR 的训练、语义或邻近关系模块**，不能用于反驳完整 HSPR。

HSPR 已直接讨论 DUET 回走和的问题；发现这段实现与修复分数公式本身也不足以形成新的论文贡献。
