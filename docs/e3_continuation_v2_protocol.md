# E3 v2：完整续跑监督与可恢复失败数据

本轮沿用用户目标：相对固定 DUET，完整 R2R val_unseen 的 SR 提高至少 5 个百分点，SPL 不下降。对应旧基线至少 1,798/2,349 条成功，SPL ≥60.40984985。尚未达到；训练侧的机会或压力测试不能证明该目标。

## 为什么改数据与干预位置

旧 E3 fit 仅有 3 条独立指令提供成功救回监督，单次随机偏航主要增加绕路。新版在自然轨迹之外，固定早期连续两次和较晚三次合法偏航；策略只在偏航结束后尝试一次纠正。全部 15 次决策预算保持不变，偏航和最终返回都计费。

待检验的研究贡献是：有明确执行预算的失败数据生成，能否帮助小型因果历史模块判断一次动作干预的最终完成收益。GRU、价值预测、相对回报和收益门控都有先行工作；同一状态减去原动作价值本身不构成新动作排序原理。必须通过匹配对照确认实际增量。

## 固定采集

配置入口：`configs/e3_continuation_v2.json`。新 schema、新运行目录，保留旧 E3 probe。

- 首轮 512 条 train_fit、128 条 train_dev，按既有房屋划分与场景分层规则选样；先以独立目录做每划分 16 条工程冒烟。
- 四条件：自然；step 2 单次偏航；step 1、2 两次偏航；step 2、4、6 三次偏航。所有步数从零开始。
- 偏航动作依据指令 ID、种子、条件、步数和合法候选的哈希选择，不读取目标或分支结果。
- 状态为最后计划偏航之后的首步、首步加 3、原 STOP 步，去重；自然对应 step 0、3 和原 STOP。原预算强制终止时不再干预。
- 每状态保留原动作、两个原分数最高的合法替代移动及 STOP，去重。分支严格重放同一前缀，执行候选一次，之后仅运行冻结 DUET。
- 每个原动作 anchor 要重现全路径与指标。强制动作后恢复原 STOP 概率，保留历史终点返回语义。
- 保留所有原指令、条件及未成功施加偏航的情况，不能只留下可救回样本。

训练特征只来自当时冻结 DUET 的候选表示、原分数、已发现几何、已执行路程与剩余预算。历史 token 按时间交替保存 STOP 上下文和过去已执行动作，最后为当前 STOP 上下文，不包含当前动作之后的信息。512 条 fit 可按固定 ID 排序交错分为两个无交集分片并行采集；合并前核对完整指令/条件覆盖，复制后逐文件 SHA 验证，不改变样本集合。缓存与在线部署统一转换为 FP16；模型运算使用 FP32。真值和完整分支结果只用于训练标签和最终评估。

工程支持门槛为至少 32 条有成功救回机会的独立 fit 指令，覆盖至少 12 个 fit 房屋；这是预先选定的工程门槛，不是统计充分性保证。若不足，只允许另立身份、记录一次固定扩大到 2,048 条 fit；否则应改数据机制，不用重复分支行冒充独立样本。

## 五臂训练

模块约 36.4 万可训练参数，DUET 冻结；所有臂保留相同容量和候选集合：

1. 相对最终 SR/SPL + 新增因果历史。
2. 绝对最终 SR/SPL，部署时同样减去原动作预测。
3. 同状态、同候选约束下的专家动作 CE；不训练额外未来结果安全头。
4. 相对收益、只输入当前 STOP 上下文，去除额外历史信息；DUET 原表示仍包含它自身的历史。
5. 完整比较器，只用自然和旧单次偏航机制的数据，匹配原指令与优化更新预算。

第五臂在本轮相同指令集重新采集单次扰动，未复用旧 64 条 probe 作为等规模对照。被重复采样的行必须报告为重复，不增加独立样本数。各原指令总训练权重相同。

共同 seed 0、AdamW、学习率 3e-4、20 epoch、batch 32；完整结果回归的 rescue/harm 权重均为 4。只从 epoch 5/10/20 选模。SR 门槛固定为 0/0.05/0.1/0.2/0.4，SPL 门槛固定为 0；teacher 使用对应的候选概率减原动作概率门槛，不能把它称为预测 SR。

## 选模与真实导航

一次干预前始终沿同条件原轨迹，采集已覆盖全部允许干预的状态。因此可以在完整分支缓存上先按观察特征依时间选取第一次通过门槛的动作，再读取该动作的已执行结果计算指标。结果标签不能进入选择函数；此离线计算需用真实在线导航逐轨迹验证。

自然开发 SR/SPL 不低于同面板基线的候选中，优先早期两次/较晚三次偏航面板的净成功增量，再比较 SPL、干预次数和较早 epoch。四种条件分别报告；困难面板统计是条件案例数，需要另报指令去重。

选定后运行完整自然 train_dev（2,890 条）做损害检查，并核对固定压力面板的在线与离线结果。没有满足门槛的候选则如实报告失败，保留固定末轮和严格门槛的诊断结果，不用 val_unseen 调门槛。

当前 pilot 已用 7/12 个 variant，本轮五臂最多各使用一次完整 val_unseen；所有臂的 checkpoint、门槛、源码必须在首次正式访问前共同封版并登记账本。需要跨 WSL/T4 重跑正式 DUET 基线时也单独登记既有基线 variant 的访问。正式验证结果不得用于训练标签、归一化或重新挑选 epoch。确认三种子和官方盲测必须另行提前登记。

## 运行与保存

在 WSL RTX 4060 Laptop 8 GiB 上运行；全部训练资源已本地化，可离线运行。每个完整指令条件 bundle 原子写入并经持久目录 SHA 读回后确认，掉线只需重做未完成 bundle。训练保存模型、优化器、RNG 和采样游标，备份确认后清理旧快照，最优模型保留；恢复必须核对源码、数据与配置身份。

研究数据和 checkpoint 保存在 WSL 的 `outputs/` 及 `/home/xxl/vln-backups`。源码与小型报告同步 Git 和本地。这是同机持久备份，原云盘历史归档保留。
