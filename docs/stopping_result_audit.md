## 结论

**历史终点误选有实际规模，但目前不提升为新的 STOP 论文方法。** 固定 DUET 的 669 条失败指令中，212 条曾在真正获得观测的决策位置进入目标 3 米范围，覆盖 151 条不同参考路径、11 个房屋。这个机会明显多于 S0，但它不证明动作数偏置、不证明停止后继续探索有益，也没有建立超越已有历史目标重排方法的创新。

已登记的简单分数未提供清楚改善：原始 STOP logit 只净增加 2 条成功，同时增加平均路径长度；logmeanexp margin 净增益为 0。不得据此挑选一个分数作为有效新策略，或继续在这份验证报告上搜索阈值、组合和子集。

## 2. 已有错误机会

| 项目 | 结果 |
|---|---:|
| 基线成功 / 失败 | 1,680 / 669 |
| 基线 SR | 71.5198% |
| 实际观察历史中存在成功位置 | 1,892 |
| 有成功历史位置但最终失败 | 212 |
| 这些错误的不同参考路径 / 房屋 | 151 / 11 |
| 212 条占全部指令 / 全部失败 | 9.0251% / 31.6891% |
| 在同一完整轨迹上完美选择已观察终点的 SR 上限 | 80.5449% |
| 固定轨迹未提供成功决策位置的失败 | 457 |

上限比基线高 **9.0251 个百分点**，使用了目标标签选择历史终点，不能当成可实现方法收益。151 是不同参考路径数量，也不能把同一房屋或同一路径的多个语言指令当成完全独立样本。

本次报告的标准 OSR 失败差额也为 212，恰好与实际观察历史差额相同；实现仍严格区分两种定义，不能据数值相等把未观察的中间路径节点加入未来方法的候选集合。

结束标志为主动 STOP 2,289 条、达到动作上限 68 条、无合法移动 0 条，其中 8 条同时满足主动 STOP 与上限。三个分组不是互斥分类。历史可恢复失败中，主动 STOP 标志组有 196 条，上限组有 19 条，同样不能直接相加。这不是只发生在超时回合的机会。

**不能把其余 457 条认定为“过早停止”。** 它们也可能来自错误路线、未找到目标或预算不足。S1 没有观察基线停止后的继续结果。212 条则说明已走轨迹拥有可选成功终点，不说明提前在线识别该终点已经可行。

## 3. 既定简单评分对照

以下是**保持整个原始移动前缀、只重选最终终点并计入返回路径的反事实结果**，不是修改在线策略后重新 rollout 的导航成绩。五种方法均覆盖全部 2,349 条指令。

| 最终终点规则 | 成功数 | SR | 相对基线救回 / 损害 | 平均完整路径（米） |
|---|---:|---:|---:|---:|
| 原历史最大 STOP 概率 | 1,680 | 71.5198% | — | 13.9411 |
| 最后决策位置 | 1,673 | 71.2218% | 5 / 12 | 13.7410 |
| 原始 STOP logit | 1,682 | 71.6049% | 13 / 11 | 14.0166 |
| STOP − 最大移动 logit | 1,678 | 71.4347% | 1 / 3 | 13.9268 |
| STOP − logmeanexp（移动 logits） | 1,680 | 71.5198% | 1 / 1 | 13.9296 |

原始回退改变 61 条指令的终点，救回 12 条、损害 5 条，净救回 7 条，平均追加返回距离 0.2001 米。单纯取消回退会损失 0.2980 个百分点 SR；因此不能把“回退发生”本身当作错误。

raw STOP 的净增益只有 **0.0851 个百分点**，平均完整路径增加 **0.0755 米**，并存在 11 条损害。报告未提供预登记的配对显著性检验或跨训练种子证据，本审计不追加统计检验，也不把这个正号认定为稳定收益。logmeanexp 的 0 净增益不支持“去掉动作数量项即可解决”的简单解释，但也不足以证明所有动作竞争效应都不存在。

反事实 SPL 仍缺失：缓存没有官方 GT reference path 长度。不能用起终点最短距离替代，也不能由平均长度下降推断 SPL 必然提高。

## 4. 实现与解释边界

- `StopTraceObserver` 复制当前 logits、合法 mask 和已发现图距离，返回原 `nav_outs`；目标距离单独写到 `analysis_only` 标签，未进入策略。
- 历史选择包括全部真实决策状态及强制结束状态，以第一个最大值复现上游严格 `>` 的平局规则。当前协议禁止重复决策位置，避免把位置键覆盖行为误当独立时间候选。
- 基线轨迹的每段移动用当时已发现图验证，最终返回使用最后状态的图距离；实现保存完整前缀，不裁掉走错路段。目标定义是 R2R 的终点距离 `<3 m`，不是精确到达目标点，也不等于完整指令已被遵循。
- 无移动时的 margin 不会伪造为有限高置信度；本次此类回合为 0，因此没有评分覆盖率差异。
- CPU 重建的历史概率选择须匹配实际 CUDA rollout 的最终位置才会提交；本次端点检查通过。该检查证明这里的最终选择一致，不要求 CPU/GPU 每个 softmax 浮点值逐位一致。
- S1 是明确登记的 `val_unseen` 开发诊断，已经看到了验证标签，不能称盲测或留出的最终检验。

## 5. 研究建议

将 S1 结论固定为：**“观察历史终点误选的机会成立；动作数因果解释和新 STOP 方法均未成立。”** 停止在本报告上追加自适应分数搜索，不立即以 raw STOP 的两个净成功启动论文主线。

独立目标分类与历史终点重排已有直接先行工作：[Mind the Gap §3.4–3.5](https://arxiv.org/html/2308.03244)；回退时机、回退位置及搜索终止也已有 [FAST §2、§4.3](https://arxiv.org/html/1903.02547)。因此，S1 提供工程适配的错误量，不能替代创新论证。

如果后续另行批准 STOP 工程实验，首先用仅由 `train_fit` 产生的数据建立同容量独立 sigmoid 目标分类 / 历史重排强对照，先证明训练场景中有足够不同路径上的错误可学。更复杂候选只有在超出该对照、有明确可证伪机制，并以独立登记的完整导航评测计入返回成本后，才值得讨论论文规模。停止后继续、途中返回后再次导航均需真实新 rollout；本次表不能为其提供效果保证。
