# 到达监督与多来源代理证据：查新及可证伪性审计

日期：2026-10-03。审查对象：`docs/research_plan.md` 当日版本。范围：冻结 DUET，复用视觉特征，T4 / 12GB 级设备优先的小论文预研。本文没有运行新导航实验，也没有验证涨点。

## 1. 核心判断

**建议有条件继续一次有预算上限的诊断，不建议直接立项为已经成立的论文方法。** 本次检索没有找到完整覆盖“同一未访问候选的不同来源证据，用后来到达时的观察监督其决策用途”的工作；这只是有限查新的结果，不能证明新颖性。

目前最危险的不是模型太小，而是以下三点：

1. **“重复来源导致虚假置信”不符合默认 DUET 的主要运行协议。** 已访节点通常不能再次作为全局动作终点，回走路径的中间节点也不重新采集观察。同一 `(source, target)` 被反复写入不应先验假定为常见故障。主问题应收窄为：不同来源的观察先取平均，是否丢掉了对当前动作真正有用的信息。
2. **到达后的全景不是到达前代理观察的正确答案。** 它新增了视野、位置和内容。把它装入旧状态的未访节点，可能产生骨干未见过的输入组合；分数变化可能只是表示类型变化，不能称为“可靠性真值”。当前方案已经承认这一点，但仍需实验排除。
3. **“未来观察只在训练时提供监督”已经很拥挤。** 从 VLN-SIG 到 NavQ、LatentPilot，未来视觉监督及其动作收益都有先行工作。必须证明收益与保留不同来源证据有关，而不只是又加了一个未来特征或分数预测任务。

可以保留的故事是：**到达确认是否能帮助模型选择当前已经看过的来源证据，并且比仅靠动作标签学习选择更有效？** 其成立依赖现象、增量监督和完整导航三层证据。冻结骨干和低训练成本是实现约束及可报告优点，不能单独充当方法创新。

## 2. 代码事实与需要修正的论据

审查基于项目固定的 DUET 提交 `93e8b233164bc079a6db48b8a0a78d123ec8de41`；本地增加的采集钩子不改变以下上游逻辑。

- `rollout` 对当前位置写入全景平均特征，对尚未访问的邻居写入朝向该邻居的方向特征；`GraphMap` 对多次写入求和计数后取均值，到达后覆盖。[agent.py](https://github.com/cshizhe/VLN-DUET/blob/93e8b233164bc079a6db48b8a0a78d123ec8de41/map_nav_src/r2r/agent.py)、[graph_utils.py](https://github.com/cshizhe/VLN-DUET/blob/93e8b233164bc079a6db48b8a0a78d123ec8de41/map_nav_src/models/graph_utils.py)
- `act_visited_nodes` 默认关闭；已访节点被标为 visited，不能作为正常全局动作终点。`make_equiv_action` 将已知最短路计入轨迹，然后直接在动作终点建立模拟器状态，中间节点没有逐个进入观察更新循环。[parser.py](https://github.com/cshizhe/VLN-DUET/blob/93e8b233164bc079a6db48b8a0a78d123ec8de41/map_nav_src/r2r/parser.py)、[agent.py](https://github.com/cshizhe/VLN-DUET/blob/93e8b233164bc079a6db48b8a0a78d123ec8de41/map_nav_src/r2r/agent.py)
- 因而，默认全局/融合策略下，应先实测**不同来源数量**与**决策相关性**。同源去重保留为数据完整性和鲁棒性测试；不能通过开启重访或额外采集中间节点，制造原协议没有的问题，再称为修复原 DUET。
- 上游专家实现同时存在 `spl` 与 `ndtw` 选项，不能把所有 DUET 训练标签都描述成只考虑离目标的最短距离。新缓存须记录实际专家配置；用 oracle 代价分析决策时，应区分目标接近程度和路径遵循。[agent.py](https://github.com/cshizhe/VLN-DUET/blob/93e8b233164bc079a6db48b8a0a78d123ec8de41/map_nav_src/r2r/agent.py)

这些是对现有协议的限制，不是否定不同来源均值压缩可能有问题。多来源是否常见、是否影响最终失败，仍待真实日志回答。

## 4. 只保留一个首选假设

> **H：在正常 DUET 协议产生的多来源候选中，均值之外的来源差异包含可泛化的动作信息；以到达观察构造的辅助监督，能比同证据、同容量、同动作训练的注意力模块更好地利用这些信息，并改善完整导航。**

H 不声称某来源具有绝对可靠性，不声称方差等于不确定性，也不声称到达表征替换给出了正确动作。它要求同时回答三个问题：

1. 保留来源是否有用？
2. 到达监督是否在来源保留之外有增量？
3. 该增量是否能转化为正常环境中的完整导航收益？

只有预测损失下降，或者只有相对未经适配的 DUET 涨点，都不支持完整 H。

## 5. 五个可能使研究失败的假设

### 5.1 多来源现象可能不足以支撑主要收益

统计单位至少区分“候选记录、决策状态、独立指令/路径、房屋”。同一候选出现在很多相邻状态不等于很多独立证据。先报告有至少两个不同来源的有效候选比例、这些候选进入最高分竞争的比例，以及多来源状态涉及的完整失败轨迹比例。若它们极少影响动作，单独解决它们不太可能支撑总体指标的稳定变化。

同源重复另行计数，预期可以为零。人工复制同源记录只能检验实现稳定性，不能作为自然故障规模的证据。

### 5.2 全景替换可能只是输入类型扰动

记原始候选相对 margin 为 `m`，保持状态不变后替换为到达表示得到 `m_arrival`，标签为 `delta = m_arrival - m`。该差值同时可能包含新语义、视野、编码尺度和分布外组合，不能直接解释为旧证据的误差。

最低检查：原值替换必须严格为零；记录特征范数和编码条件；比较真实到达配对与按距离、来源数和范数分层的错配观察；分别分析单来源与多来源。只要错配观察也产生相近的“有效标签”，就不能维持到达确认的解释。上述检查仍不能证明替换是因果干预；它只是一个需要实测价值的训练目标。

### 5.3 整个候选的一个差值不能标注每个来源的可靠性

所有来源共用一个 `delta`，最多监督候选级修正。注意力权重也不能直接当作真实来源可靠性。若要写“辨别哪些来源可靠”，至少要证明在同一状态移除/替换具体来源的效果，与模型选择有一致关系，并且这种关系超出几何和原分数的解释。否则应把结论限定为“来源表示帮助候选评分”。

不建议为了补故事立即加入复杂来源伪标签。先通过下一节的二维对照检验来源是否真的参与收益。

### 5.4 有到达标签的样本存在选择偏差

自然轨迹只为到达过的候选提供标签，且常偏向骨干本来就偏好的动作。必须保存采样机制，并为训练房屋中的合法相邻候选做有限、分层补充采样。自然采样和补充采样分别报告；没有到达的样本是未知，不是负例。

划分先按训练房屋完成，再生成标签与拟合归一化；同一房屋中的多条相关记录不能随机拆到诊断训练与验证两边。补充采集后的普通头和普通注意力也必须获得同样的数据，否则监督效果与新增数据量混杂。

### 5.5 信号可能在到达前不可预测，或只改善离线模仿

门后新内容可能无法从既有观察推断。一个看过到达观察的教师能改变动作，不代表仅看过去的学生能学到这种变化。必须分别报告教师替换效果、学生预测效果和学生完整 rollout，不能称教师结果为可实现的性能上界。

同时，全景替换让一个候选更像目标，并不保证完整路线正确；R2R 的最终到达与 R4R 的指令遵循也不能混为一谈。若只降低一步动作损失而未改善完整导航，课题尚未通过。

## 6. 最小机制实验：二维对照，先小后大

### 6.1 数据与廉价诊断

沿用首批约 1,000 个训练房屋决策状态作为覆盖率试采集，不把其数量当统计充分性的保证。冻结 DUET、源特征、专家配置、状态列表和按房屋划分。保留每个候选的来源集合、均值、相对几何、基座 logits，以及分离存储的到达标签。

先用 CPU 或缓存训练小预测器：几何/年龄/基座分数；加均值特征；再加来源集合。比较其对预先定义动作错误或动作代价的增量预测，不能只预测由同一个模型直接产生的 margin。报告按房屋的结果和不确定区间。若有效多来源样本太少，至多进行一轮预先限定规模的补采；仍不足则以“无法在预算内验证”停止，不能把低检验能力写成现象不存在。

### 6.2 四个核心训练组

所有组使用相同缓存、动作标签、训练步数和相近可训练参数量；模型选择仅用保留训练房屋。主干冻结。二维对照如下：

| 表示 | 只用动作监督 | 动作监督 + 到达辅助目标 |
|---|---|---|
| 均值表示，加同一套几何信息 | P0 | P1 |
| 来源集合，普通指令条件注意力 | S0 | S1：待验证方法 |

- `S0 - P0` 检验保留来源的价值。
- `S1 - S0` 检验到达监督的增量，是最重要的比较。
- 比较 `S1 - S0` 与 `P1 - P0`：如果两者相同，现有证据更像普通辅助监督的收益，不能强调它解决了来源混合问题。
- 均值组可保留来源数等相同标量几何条件，但不能暗中输入各来源视觉序列。参数匹配靠扩大普通小头完成，不用无效参数凑数。

最低附加排除项仅两项：

1. **S1-shuffle**：在训练分层内打乱到达配对、匹配标签尺度，检查是否只是额外损失的正则作用。
2. **S1-feature**：同源集合与同预算，直接预测到达视觉特征。它是未来视觉辅助学习的简单实现，不能标为复现 VLN-SIG 或 LatentPilot；它用于检验新监督是否比普通未来特征学习更值得采用。

均匀聚合、最新来源、几何加权和原始 DUET 均保留为廉价基线。无需在首次诊断时把全部组合做成大规模消融表。

### 6.3 最小可实现结构与算力边界

第一版只需要有界来源集合（例如最多 4 条）、小投影/注意力、候选级有界有符号修正及一个训练辅助预测头。修正必须能升分和降分。已访节点继续采用既有直接表示；推理不读未来标签，不新增探索步数或隐藏视觉观察。

优先在冻结特征上建立轻量旁支，以便先完成二维实验。如果必须在图 Transformer 前替换聚合特征，应单独测激活显存和前后向时间；冻结参数不能免除这一成本。当前底座的 T4 冒烟只能证明旧管线能运行，不能直接证明新结构及完整训练也能运行。

采集和标签生成先单独测每千状态耗时、峰值显存及缓存体积，再定全量预算。这里不承诺未经测量的卡时，也不建议先租长时段 GPU 等待研究假设成立。

## 7. 明确停止条件

以下是决策门槛，不是发表保证。数值预算和允许的模型选择次数应在看到新方法效果前记录。

| 门槛 | 继续所需证据 | 停止或收窄的情形 |
|---|---|---|
| 现象 | 正常协议下有足够独立、多房屋的决策相关多来源案例 | 只有人工重复/破坏数据才出现问题；补采后仍无法在预算内检验 |
| 标签 | 真配对比匹配错配更有用；学生可从现有输入预测有用变化 | 变化主要由范数/类型扰动解释；未来信号不可预测；有害探索偏置明显 |
| 来源机制 | S1 超过 S0，且来源结构参与收益 | 只有 S0 涨点：这是普通聚合；只有 P1/S1 同幅涨点：应撤回多来源解释 |
| 监督必要性 | 真目标超过打乱目标，且胜过或提供区别于直接未来特征回归的收益 | 打乱标签同样有效；简单未来特征目标同等或更好且无额外机制证据 |
| 完整导航 | 在固定开发协议上改善真实完整 rollout，随后再做正式评测 | 只改善缓存分类/loss；只超过原始 DUET而不超过同训练强对照；SR收益靠显著增加路径获得 |
| 论文规模 | 固定方法后，三种子、第二基准/骨干、成本及失败分析支持相同解释 | 只在一个挑出的子集或一次种子上成立；必须反复换故事才能解释结果 |

“没有显著差异”在样本过小时只表示结论不充分；但到达预定预算仍不充分，可以停止投入，不需把统计不确定性包装成正结果。

## 8. 对现有计划的具体结论

现有方案已正确包含：未来信息隔离、相同数据强对照、标签不是可靠性真值、选择偏差、完整导航指标、三种子与迁移验证。这些应保留。

本轮建议增加或收紧四处：

1. 把同源重复从核心动机移到数据检查，依据正常运行日志决定是否再讨论。
2. 将宽泛贡献“后续观察学习当前决策价值”收窄为 H，明确 VLN-SIG、NavQ、LatentPilot 的边界。
3. 用 P0/P1/S0/S1 二维实验替代仅比较注意力与注意力加辅助损失，防止把普通未来监督误写为来源机制。
4. 将 MAM 全文监督细节列为正式定题前的查新缺口；未取得全文时如实保留限制，不能用摘要推断其没有相似训练信号。

**当前最终建议：继续低成本证伪，暂不扩大训练；没有理由现在堆加模块，也没有证据需要立即换题。** 若核心门槛失败，应结束这一假设并重新选题；本审计未发现其已被完整覆盖，因此不为凑选项额外提出替代方向。


## 后续候选：执行首跳与跨尺度融合（2026-10-03）

这是第一条 arrival-margin 监督停止后提出的探索性候选，尚未产生方法收益。代码事实是 DUET 将已访问局部邻居的加权 local logits 求和，再把同一值加给每个非局部未访节点。**这个问题已由 HSPR 直接讨论，不能当作新发现。**

- [DUET 原论文](https://openaccess.thecvf.com/content/CVPR2022/papers/Chen_Think_Global_Act_Local_Dual-Scale_Graph_Transformer_for_Vision-and-Language_Navigation_CVPR_2022_paper.pdf) §3.2.4、式 6–8定义共享回退分数。
- [HSPR](https://arxiv.org/pdf/2403.11541) §III-C 是直接先行工作；[官方实现](https://github.com/iCityLab/HSPR/blob/main/reasoning_nav_src/models/vilmodel.py) 的 residual fusion 在纯视觉分支给远端再次加自身 global logit。将这一分数规则用于冻结 DUET 只是对照，不是完整复现 HSPR 的训练和 proximity 模型。
- [NavGPT-2](https://arxiv.org/html/2407.12366) 附录 A.3复述 DUET 共享回退机制，其策略主要使用全局分支，提示应比较去除局部分支的解释。
- [GraphNav 2019](https://graphnav.stanford.edu/) 使用图规划与视觉行为执行，不能与未经核实的同名 VLN 后续论文混淆。

若对全部有效、已加权的 local logits 加常数 c，原式使远端增加 Kc、近端与 STOP 增加 c，K 是已访问局部邻居数。这仅说明融合对分数绝对零点敏感；共同偏置受到融合损失训练，不能把它当成必然不合理的模型等价变换或自然错误证据。mean-back、logsumexp-back、actual-firsthop 均可在 K>0 时让所有动作增加同一 c，因此需要同场比较。远端之间原本也不会因这个共同值改变排序。

尚可检验的窄问题是：在与共享 mean/LSE、HSPR 式替代比较后，按实际执行路径首跳分配局部证据是否有额外价值。保持分数集合而打乱目标—首跳对应关系可作为后续预先登记的方向关联对照。当前 R0 固定五种规则仅用已有训练房屋状态做 CPU 机会诊断，不代表完整导航实验。

简单 g(v)+l(firsthop(v)) 并不保证首跳总概率等于局部策略概率。按组减去 logsumexp(g) 才形成标准的条件概率分解；这个公式本身不是创新。任何学习方案还应比较同容量普通融合头与纯全局对照，不能凭一处规则修正就宣称论文规模已满足。
