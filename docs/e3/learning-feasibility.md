# E3 训练可行性：把一次干预移到错误动作之前

## 建议

优先研究一个**在线动作后续收益比较器**：在 DUET 每次决策时，比较“执行原动作”与“改为另一个合法动作后，让冻结 DUET 继续至结束”的完整导航结果。输入只包含当前已见前缀；推理只加一个小头，不执行额外分支搜索。首轮限制**每条任务最多改一次动作**，其余步骤全部复用原 DUET。

它允许在走错分支或过早 STOP 前纠正方向，因而能进入原策略没有到达的区域。相比终止后历史终点重排，这是更有可能提供较大 SR 改善空间的作用位置。不过，**现有证据不能保证达到相对 DUET +5 个百分点**。目标应固定为 SR ≥76.5198%、SPL ≥60.40985%，而不是把目标写成预期结果。

本说明只读现有代码、既有汇总文档和训练审核；没有读取新的验证逐任务数据、运行导航或修改旧实验。

## 1. 为什么停止后小头不适合继续承担 +5pp 主目标

- E2 的固定探索和停止时刻完全不变，只能重选已经观察过的历史终点，无法修复“根本未到达目标附近”的失败。
- E2 自然训练 4096 条中仅 38 条含正 ΔSPL 候选；加入一次扰动后，两条件合计只有 91 条独立正收益指令。20 轮训练下降的 loss 没有带来自然开发失败救回。
- E2 的开发原基线 SR 为 97.8201%，仅剩 2.1799pp 理论空间。**不可能要求这个开发集也上涨 5pp 来预判正式目标**。它适合检查自然分布损害，需要额外的训练场景扰动保留集检查恢复能力。
- 已完成的正式汇总中，E2 relative 只改 27 个终点，救回 1、伤害 9。要在 2349 条任务上获得至少 +5pp，需要净增至少 **118 条成功任务**；调整末端门控的几个小数不能替代这么大的行为覆盖。

这些是作用范围和现有证据的限制，不证明所有终点方法都无效。E3 也不能把人为扰动集上的改善直接外推成未见场景 +5pp。

## 2. 模块定义：一次动作改变的完整执行后果

令状态 `h_t` 包含当前指令、真实已执行路径、已发现图、当前冻结 DUET 输出和一个因果历史状态。原动作是 `a0`。对候选 `a` 定义监督：

`U(h_t,a) = [最终成功, 完整实际路径 SPL]`。

生成标签时，从完全相同的前缀强制执行 `a` 一次，随后恢复冻结 DUET，直到正常结束或原 15 次决策上限。所有在线移动、远端目标的中间边和最终历史返回都计入路径长度。`STOP` 的含义必须是原 DUET 的真实停止及历史返回流程，不能换成“在当前点结束”而不声明。

模型预测 `U(h_t,a) − U(h_t,a0)`，同时保留可匹配的绝对效用回归对照。决策优先提高成功率，再约束完整执行效率。阈值/规则只在训练保留集固定，之后封版；预测非负不代表实际安全。

**最多一次干预的意义：** 在首次改动作前，真实状态仍位于原策略前缀上；改动作之后关闭干预头。因此“改一次后继续冻结 DUET”的训练标签与实际部署语义一致。首轮不允许一边使用单次反事实标签、一边在推理中反复改动作。若一次干预的机会覆盖不足，应明确否定本设定，再另立多次闭环恢复实验。

候选动作保留原合法 mask：原 argmax、其他合法移动中得分最高的两个，以及 STOP（去重）。移动可以指向局部邻居或已发现的未访全局目标；远端执行路线只能来自当时已发现图。没有候选时按原规则结束。不解锁不存在的节点、不读取候选未来全景作策略输入。

## 3. 表征与预算

复用 `gmap_embeds`、按 viewpoint ID 对齐的 `vp_embeds`、当前 global/local/fused logits、合法 mask、已知路线距离和前缀长度。增加一个 128 维 GRU，按时间汇总当前上下文、上一步执行动作及本步新观察；它只能前向更新，不能使用终止时完整历史回填早期状态。

建议结构：768→128 的候选编码、1536→128 的当前 STOP 上下文编码、128 维历史 GRU、候选与原动作联合比较的两层 MLP。根据是否共享编码，约 **0.5–0.8M 可训练参数**，首轮上限 **1M**；骨干全冻结，不增加每个候选的 DUET forward。

训练使用离线缓存的前缀表示和分支结果，batch 32–64，AdamW，固定种子。参数、梯度和 AdamW 状态本身远低于 100MB；实际峰值要由新模块真机 smoke 测量，不能直接用 E2 的 79MiB 作为 E3 实测。T4/12GB 的主要成本预计是标签采集时间与 CPU 特征缓存，而不是小头训练显存。

GRU、收益回归和保守门控都不是单独的新概念。本候选的待验证贡献是：**在同一可执行前缀上，把动作造成的最终恢复收益与代价作为学习单位，并保持单次干预标签与在线策略一致**。需要下述强对照证明它优于普通动作模仿；不提前宣称首创或已达到论文规模。

## 4. 数据方案：制造可恢复偏离，同时保留自然分布

### A. 一次固定的小规模机会检查

建议先选 512 条 train_fit 原指令，按场景分层固定 ID；另取 train_dev 中固定 256 条用于恢复检查，保持场景隔离。每条指令收集：

1. 一条自然 DUET 轨迹。
2. 一条按固定哈希选择早期合法非原动作候选的偏离轨迹；选择过程不使用目标或参考路径，不能事先断言该候选一定错误。偏离动作必须真实执行并继续观察。

每条轨迹最多抽取四个状态：首次两支路分歧状态、一个固定哈希中段状态、原 STOP 决策状态等；具体无标签选择规则需在采集前写死。不得只保留最终失败的轨迹，也不因分支结果好坏替换状态。

从每个选中状态收集候选动作的完整继续结果。原动作分支可复用同一真实轨迹的后缀；两个替代移动及 STOP 按需求重放。**标签是完整继续结果，不是“朝目标近了几米”或预测下一视点 logit 的代理。**

对每个前缀分支复放，先核对原动作分支的全部观测 ID、朝向、图状态、导航 logits、终点、轨迹与指标一致。未来观察只用于该分支的标签生成，不能混入分支发生前的小头输入。保存标签来源、分支动作、图路线、剩余预算和 SHA。

### B. 通过后才扩大一次

建议正式首轮使用 2048 条原指令的自然/偏离各一份，共 4096 条前缀轨迹；每轨迹至多四个状态、每状态至多两个需要额外继续的移动分支。额外完整继续最多约 32768 次，STOP 分支只需实际返回和评估。若自然原 STOP 状态需要两个继续分支，也计入此预算。

每条分支按独立随机数状态重放原前缀，避免前一个分支污染下一分支。直接复用 E2 终点张量不能替代此采集，因为它们没有每个动作前缀及分支继续结果。

以 E2 真实 rollout 吞吐估算，这个数据量可能需要数小时 T4，取决于重放前缀、剩余步数和 Drive 写入；这是工程估算，不是已测耗时。先用 64 条测吞吐，再按**预先限定的总指令预算**评估是否能在 Colab 窗口内完成。分支任务逐条封存、分片 Drive 读回确认后清理本地，完整支持断点续采。

自然/偏离来源按固定比例混合，原指令等权，不把同一长轨迹的更多分支当成更多独立证据。正样本可以在训练侧显式重采样，但必须记录权重与原始频率，并由保持自然先验的保留集固定部署阈值。不能把人为重采样后的分类概率直接解释为真实失败概率。

### C. 辅助监督与廉价控制

所有已见状态可以从 train-only 的完整图得到教师合法动作/剩余代价，作为便宜的 CE 预热或辅助损失。但它与分支最终成功不是同一监督：近目标的动作可能使冻结策略之后失败，较远动作也可能修复路径。只有完整分支标签在匹配数据控制之外有实际增量，才能支持所提出的作用机制。

自然 train_dev 用于防止破坏已有成功与最终选模；单独、预先固定的偏离 train_dev 用于判断恢复是否学会。两者分别报告，不能用偏离开发 SR 冒充标准导航 SR。

## 5. 必须保留的对照

1. **原 DUET**：相同资产、步数和完整路径计费。
2. **现有残差动作小头 + 教师 CE/KL**：使用同样训练前缀、样本预算和接近的参数量。`features.py` / `head.py` 已提供入口。这是最重要的廉价强对照；若它取得全部改善，不能把普通动作微调包装成新贡献。
3. **同容量绝对继续效用预测**：输入、分支数据、历史 GRU、推理规则相同；推理前减原动作效用。避免再次把“减去原动作常数”本身当创新。
4. **无历史的同容量模型**：以当前上下文替代 GRU，检验新增历史模块是否必要。
5. **只用教师一步代价、无完整分支结果**：保持原指令和前缀一致，比较完整后续监督是否比便宜代理值得。

先在训练保留集筛掉无法超过简单 CE 控制的方案，再决定有限的正式导航对照。验证集已多次暴露，下一轮应在任何新结果前联合冻结模型和访问计划，不扩展阈值网格寻找 +5pp。

## 6. 建议的失败判据

以下是下一实验的候选门槛，**尚未登记，也没有数据结果支持这些具体数字**；主控应在新采集前确定最终值。

- **表示/重放失败：** 原动作分支无法复现真实继续路径或指标，立即停在工程修复，不训练、不把分支效用当真标签。
- **作用空间不足：** 在固定偏离开发轨迹中，同一候选集合的一次干预理想选择，若连原失败中的 30% 都不能救回，或没有足够失败任务供稳定判断，则不晋级当前动作集/干预预算。目标 +5pp 相当于最终基线失败中的约 17.6% 净救回，30% 是给预测损害留出余量的训练侧候选门槛。这里的“理想选择”只诊断机会；扰动开发条件比例不能直接外推到正式验证，更不能把理想选择当作方法成绩。固定偏离开发基线也可能很强，不应机械要求它上涨不可能的绝对百分点。
- **正例不足：** 扩大一次后，具有“原分支失败、至少一个替代分支成功且效率不劣”的独立训练指令少于 200 条、覆盖少于 20 个场景，则不继续靠更复杂网络推进；记录样本支持不足。次数是原始指令去重数，不是候选行数。
- **学习无效：** 固定训练预算结束后，在偏离开发集没有比原 DUET和匹配 CE 对照带来净恢复，或自然开发 SR/SPL 明显受损，则不晋级正式验证。自然/偏离精确容差与主选模规则须事先冻结。
- **机制不成立：** 若同容量 CE、绝对效用或无历史控制解释全部收益，撤回对应创新点；可以保留工程改进。
- **最终目标未达：** 正式固定验证 SR <76.5198% 或 SPL <60.40985%，明确本轮未完成用户目标。小幅提升也不能改称已达到 +5pp；不得在同轮更换 checkpoint 重算。

单次干预若机会充足但学不出来，应优先检查可见信息能否预测正确分支及分布差异。直接增加第二、第三次干预会改变训练标签语义，须作为新实验，不能作为现轮隐性补丁。

## 7. 实现入口与保留边界

新增模块独立命名，旧 E1/E2 文件及结果保持冻结：

- `src/vln_improve/features.py:build_features`：复用候选 ID 对齐、合法 mask 和仅可观察特征；扩展时建立新 schema。
- `src/vln_improve/capture.py:DecisionHook`：已有当前步骤动作修改/教师标签隔离入口；旧单步缓存不能承载完整继续标签，需要新 writer。
- `scripts/run_duet.py` 与上游 `decision_hook`：接入一次动作干预、之后恢复冻结策略；保持原始 STOP 历史证据，修改动作执行时不能把 one-hot 强制 logits 当原 STOP 置信度。
- `src/vln_improve/intervention_runtime.py:TerminalIntervention`：参考真实路径计费、原 STOP 证据恢复和标注与输入隔离方式；不要在旧类上直接增加在线动作行为。
- 既有 `replay_branches.py` / `branch_observations.py`：可复用图与原前缀一致性检查，但旧工作只验证到达观测；**不等于已经具备完整继续的分支恢复器**。
- `CheckpointStore`：复用模型、优化器、RNG、游标、历史的立即备份与读回验证，采集器另外记录完整分支任务游标。

建议新增 `continuation_intervention.py`、`collect_continuation_branches.py`、`train_continuation_intervention.py` 和独立实验配置。第一个可审查交付应是：64 条真实前缀的原分支一致性、训练侧候选作用上限和新增标签的正例覆盖；通过后再投入大规模采集。
