# E3：在线动作干预的设计与训练侧可行性

日期：2026-10-06。**目标是相对原 DUET 的 SR 提高至少 5 个百分点、SPL 不降；当前尚未达到。E3 预测模块尚未训练。** 本页记录设计依据与固定训练房屋上的完整分支实验，不能把标签已知时的理想选择当成方法成绩。

## 1. 目标与改动位置

原 DUET 在完整 2,349 条 `val_unseen` 指令上 SR=71.5198、SPL=60.40985。目标要求至少 1,798 条成功，即净增加 118 条。数据、模型初始化和完整路径计费必须相同。该验证集已经参与本项目开发，最终论文还需要多种子及独立测试证据。

E2 训练和导航闭环已完成：相对收益头 SR=71.1792、SPL=60.34137，未超过 DUET。它改了 27 个终点，救回 1 条、损害 9 条。既有 S0002 诊断还显示，669 条原失败中有 457 条原探索没有观察到成功历史节点，终点重排无法处理这部分。见 [E2 结果](e2_loop_results.md)和[已完成诊断](e2_failure_diagnosis.md)。

E3 因此把干预提前到导航过程：**比较执行原动作与执行另一个合法动作后，原 DUET 完整继续运行的结果。** 它可以改变之后看到的区域，也可以纠正过早停止；实际路程及最终返回仍计入 SPL。

## 2. 拟增加的模块

候选名称：**完整续跑收益驱动的在线动作比较器**。这是待验证的方法，尚不声称首创。

```mermaid
flowchart LR
    A[当前指令、已见历史与发现图] --> B[冻结 DUET]
    B --> C[原动作与合法替代动作]
    C --> D[小型动作比较器：预测 ΔSR、ΔSPL]
    D --> E[保留原动作，或改一次动作]
    E --> F[冻结 DUET 继续至结束]
```

- **训练标签：**从同一个真实前缀重放，执行候选一次，其后只运行原 DUET。用整个实际执行结果减去原动作分支的结果。训练真值和未来观察只能生成标签。
- **输入和结构：**复用当前 DUET 的语言/候选表示、原分数、已知路径成本和剩余预算。拟加入小型因果历史编码与候选—原动作比较头，可训练参数以不超过 100 万为首轮约束；此参数量和训练显存尚未实测。
- **部署语义：**首轮每条任务最多改一次动作。改动前沿原策略前缀，改动后关闭比较器，这与训练标签的继续策略一致。推理不执行多条分支，不免费读取未来图像。
- **选择规则：**保留原动作作为明确选项，在训练开发集固定预测收益门槛。预测的 SPL 非负不构成实际不降的保证，必须由完整导航检验。

### 小论文需要证明什么

可研究的主问题是：**完整执行后果的监督，是否比普通专家动作纠正更适合选择何时、向哪里纠正冻结导航器。** 因果历史编码是否有额外作用，应由去除历史的消融检验。

价值学习、进度监测、相对回报和选择性恢复都有先行工作。对同一状态减去原动作价值是常数平移，本身不改变理想动作排序。因此至少需要：

1. 同输入、同容量、同分支数据的绝对 SR/SPL 价值头，推理同样计算相对原动作的差；
2. 同访问状态、同预算的专家动作纠正头；
3. 当前信息与因果历史的受控消融。

如果增量都能被绝对价值或普通纠错解释，不能把“相对收益”作为独立方法贡献。已核验的 ENP、NavQ、NavGRPO 等直接 DUET 改进并不支持轻量插件必涨 5 个百分点；比较设置及最近工作见[一手文献核验](../docs/e3/prior-art-feasibility.md)。

## 3. 本轮固定实验

本轮先检验候选动作是否提供真实可恢复机会，**不训练比较器、不新增官方验证访问**。

- 原指令：64 条 `train_fit` 与 64 条 `train_dev`，按场景分层固定选样；两边房屋隔离，但原 DUET 已训练见过这些房屋。
- 每条分别运行自然条件和零起算 step2 的一次固定合法动作扰动；未实际施加扰动的样本仍保留。
- 自然状态取 step0、step3、原终止步；扰动状态只取 step3、step6、原终止步，去重并保留真实存在的状态。
- 候选包括原执行动作、原分数最高的两个合法替代移动和 STOP；强制终止时只允许 STOP。
- 每个候选重放完全相同的实际前缀、强制一次、完整续跑；原 15 次决策预算不变。强制 logits 后恢复原 STOP 证据，防止同时篡改历史终点选择。
- 每条分支经云盘原子写入、SHA 回读和任务清单确认后才算完成；源码、配置、资产及样本身份不匹配时拒绝续用。

自然完整 `train_dev` 的原 SR 已达 97.82%，剩余空间仅约 2.18 个百分点；不能要求它也涨 5 来判定未见房屋是否可行。扰动机会同样不能直接外推到自然验证导航。

配置：[e3_continuation_probe_v1.json](../configs/e3_continuation_probe_v1.json)。实现：[采集入口](../scripts/probe_continuation_actions.py)、[单次干预与存储](../src/vln_improve/continuation_probe.py)。

## 4. 工程核验

本地 24 项测试通过。真实 T4 冒烟完成 4 条参考轨迹和 40 条分支，11 个原动作 anchor 的全路径/指标一致，全部前缀检查通过，logits 最大绝对差为 0。模型峰值分配显存 762,597,888 字节（约 0.71 GiB）；这是采集器实测，不能当成未来 E3 训练显存。

从同一云盘完成态恢复到全空本地目录后，44 份任务记录、清单和完成汇总逐字节一致。这里验证的是完成态恢复；云对象写入后、清单确认前中断的恢复由本地故障注入测试覆盖，没有声称经历了真实 VM 驱逐。

独立审计用原始训练标注和连接图重算完整路径指标、合法边、前缀、15 步预算和 anchor。精简分支记录未保留后续 raw logits 或每步发现边清单，因此独立日志审计不能逐步证明这些字段；相关执行约束由封存源码、集成测试和原动作重放共同支持。

## 5. 固定规模结果

两组均完成，共 **128 条原指令、256 条参考轨迹、2,394 条完整分支**。每个条件的分母都是该划分的 64 条指令。下表“理想选择”使用真实标签，在已采样状态中为每条任务最多选择一次干预，并要求该条 SPL 不低于原轨迹；这是受限的机会范围，不是已训练模型成绩。

| 划分 / 条件 | 原 SR / SPL | 事后理想 SR / SPL | 存在成功救回的原指令 |
|---|---:|---:|---:|
| fit / 自然 | 95.3125 / 93.8365 | 98.4375 / 97.6608 | 2 / 64 |
| fit / 单次扰动 | 98.4375 / 63.1041 | 100.0000 / 67.5943 | 1 / 64 |
| dev / 自然 | 100.0000 / 98.6018 | 100.0000 / 99.6081 | 0 / 64 |
| dev / 单次扰动 | 92.1875 / 57.2525 | 100.0000 / 64.9901 | 5 / 64 |

两组共 **683 次原动作 anchor 检查**通过，前缀 logits 最大绝对差为 0。独立连接图审计核验 2,650 条完整路径、20,305 条相邻边和 15,900 个指标值，最大浮点差为 1.42×10⁻¹⁴。两进程各自峰值分配显存约 0.71 GiB，同时运行时观察到设备占用约 1.9 GiB。采集进程各运行约 13 分钟，因共用同一 T4 并行，不能用这两个耗时直接比较方法速度。

救回类型的进一步核对显示：扰动 dev 的 **5 条可救回失败分布在 5 个房屋**；原完整路径均没有进入目标成功半径，但都存在原终止步之前的成功纠正分支。其中 1 条在本次采样的原终止步候选中已无法救回。这支持干预位置前移的动机，仍不证明模型能识别这些动作。这里的完整路径包括中间经过节点和最终返回，和 E2 的“实际观察过的历史节点”定义不同。

原始汇总：[fit](../results/e3/probe-fit-v1/probe-summary.json)、[dev](../results/e3/probe-dev-v1/probe-summary.json)。[去重分类结果](../results/e3/opportunity-feasibility.json)与[fit 几何审计](../results/e3/probe-fit-v1/audit-v2.json)、[dev 几何审计](../results/e3/probe-dev-v1/audit-v2.json)相互校验。

## 6. 根据结果作出的决定

**保留在线单次动作干预作为候选方向；当前小样本不直接晋级正式模型训练。**

1. **候选动作有机会。** 扰动 dev 的 5 条失败都有成功替代分支，说明在这一固定小样本上，单动作纠正可以产生实际恢复。这是训练场景的标签上界，不是正式验证上 +7.8125 个百分点，更不是已经达到用户目标。
2. **当前 SR 正例太少。** fit 两条件去重后只有 3 条训练指令提供成功救回监督。自然 dev 又全部成功，不能从它测出成功恢复能力。直接把这一小池交给复杂网络，尚无足够证据支持大幅 SR 提升。
3. **随机扰动偏向制造绕路。** fit 中一次扰动把 SPL 从 93.84 降至 63.10，SR 却仍接近饱和；扰动 fit 有 30 条正 ΔSPL 指令，其中只有 1 条是成功救回。效率改善样本不能替代成功恢复样本。这里是该固定样本的观察，不外推所有扰动或未见房屋。

下一版应先改进**可恢复失败的训练数据生成**：预先固定多种偏航强度和剩余预算，保留自然成功、可恢复失败、不可恢复失败三类；每条仍用实际完整分支结果标注。选样/采样权重与原始频率分开记录，避免只留可救回的任务。完成足够的独立指令和场景覆盖后，再训练本页定义的在线比较器与两种强对照。

这个调整主要解决已测出的 SR 正例不足问题。它可以形成“可恢复失败数据生成＋完整执行后果学习”的研究方案，但需要新的受控实验才能成为论文贡献。本轮没有新 E3 checkpoint，没有新增 `val_unseen` 或官方盲测成绩。
