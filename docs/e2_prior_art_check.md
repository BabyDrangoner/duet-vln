# E2：终点改写的代价与历史重评——针对性查新

日期：2026-10-06。范围：为 E1 之后的设计修改核对直接先行工作。先读了 `endpoint_prior_art_delta.md`、`prior_art_audit_20261003.md` 和 `next_method_options.md`；本轮未运行模型，未读取新的逐条 `val_unseen` 结果。本文中的候选是待验证假设，不能作为已成立的论文贡献。

## 1. 结论

**值得继续检验“相对原策略终点，学习实际执行后的净收益”；不宜把“加回走惩罚”“增加保留原决定的门控”或“用完整历史重编码”各算一个创新点。** 这三个宽泛思路都有明确先行工作。

最直接的提醒来自 **Mind the Gap**：它已经对完整历史做跨时刻注意力，并且明确区分真实返回与历史裁剪。论文 §4.3 报告真实返回时 SPL 约下降 1%，裁剪时才有更好的 SPL。因此，E1 暴露的问题有研究价值，但“发现回走损害 SPL”本身不能作新颖性主张。[论文 §3.3–3.5、§4.3](https://arxiv.org/html/2308.03244)

本轮能保留的窄范围是：**固定自然策略探索轨迹，把原 DUET 落点作为显式备选；在同一个最终信息状态下，给所有合法历史落点生成包含完整返回路线的净效用标签，学习何时、改到哪里才有收益。** 这改变的是监督单位、决策目标和执行接口，规模超过单独调阈值。是否足以支撑小论文，仍取决于同容量强对照、机制实验和完整导航收益。

## 3. 候选贡献 A：用原终点作参照的执行收益监督

### 可检验假设

在自然 DUET 历史上，终点是否处于 `<3 m` 目标区不能单独决定是否值得改写。**直接监督完整轨迹的相对效用，能比目标二分类、分数阈值和距离惩罚更好地平衡救回、误改和成功轨迹额外路程。**

### 精确定义

固定一次自然 rollout 在最终选择前的历史 `H`。令当前真实位置为 `x`，已执行探索路径长为 `L`；DUET 原本会返回的历史落点为 `b`。候选 `v` 仅来自合法已观察节点，其实际可执行返回代价为 `c_H(x,v)`。

在训练房屋内，根据目标真值构造每个候选的终局效用：

```text
y(v) = 1[d_full(v, goal) < 3 m]
reference_path_length = sum(d_full(a, b) for (a, b) in consecutive(reference_path))
U(v) = y(v) * reference_path_length / max(reference_path_length, L + c_H(x, v), 0.01)
Delta(v; b) = U(v) - U(b)
```

这里严格沿用项目固定的 DUET `env.py`：分子是参考轨迹相邻节点间最短距离的累加，**不得改成参考起点至终点的最短距离**。完整图目标距离及 `reference_path_length` **只用于训练标签、开发评分或最终评测**；推理输入仅含已知历史、语言、基座信息及发现图上的可执行路径代价。不能把参考长度或目标距离藏入输入特征。[固定版本评测实现](https://github.com/cshizhe/VLN-DUET/blob/93e8b233164bc079a6db48b8a0a78d123ec8de41/map_nav_src/r2r/env.py#L331)

同时保存 `Delta_SR(v;b)=y(v)-y(b)`，报告两种收益。若主目标选 SPL，须事先固定 SR 的最低要求，不能等看到结果后更换主指标。`KEEP` 表示保留原落点 `b` 及其返回路径，并非在当前位置直接停下。需要计算所有候选减去同一个 `U(b)`，不能只惩罚新方法的回走而把基线回走当成零。

一种最小实现是候选—基线成对小头预测有符号 `Delta`，另有同一输出中的 `KEEP=0`；选择最大预测收益，仅超过训练开发集固定门槛时改写。回归、代价敏感排序或列表损失均属已有工具，初版只固定一种，不靠多种损失叠加制造贡献。门槛的作用是控制经验风险，不提供逐条不降分保证。

### 为何有可能超过改阈值

新训练样本至少要明确区分：原错新对、原对新错、两者都对但长度不同、两者都错。原 E1 目标二分类没有显式表达后三类相对执行决策。标签应由自然轨迹内的全部合法候选构造，保留真实类比例或记录采样权重；不能只收集能救回的错误，制造高收益先验。

### 必须打败的对照

1. 不改写的原 DUET。
2. 相同自然数据、容量和输入的目标 BCE 头，配训练开发集固定的分数门槛。
3. 同一 BCE 头加发现图距离惩罚，以及校准后的目标概率除以完整预测执行长度 `p_goal(v)/(L+c_H(x,v))`；后一项是便宜的路径效率对照，不能只与较弱的线性罚项比较。调参预算与方法一致。
4. 同输入、同容量的候选绝对 `U(v)` 回归；用于检验显式参照 `b` 是否比普通效用学习更有价值。
5. 只用几何、原停止分数、时间位置的相对效用头；用于判断语言视觉证据是否参与收益。

若第 3 或第 4 项就达到相同效果，应收窄为一个有效的代价敏感终点方法，不强调“参照比较”的独立贡献。若第 5 项相同，应撤回语义改进故事。

还要承认一个代数事实：对全部候选减去同一真实 `U(b)` 不改变候选排序；只把标签从 `U(v)` 改名为 `Delta(v;b)` 不会自动产生新算法。显式参照的潜在增量在于候选与基线的联合输入、对保留原决定的决策建模以及泛化表现，必须由第 4 项等对照证明。类似地，当已执行长度足以使 SPL 分母不再截断时，同一任务的参考路径长度因子对候选比较是公共尺度，简单的概率/长度规则就可能解释收益。

## 4. 候选贡献 B：基于同一最终历史的候选—基线证据比较

### 可检验假设

E1 输入是各访问时刻保存的跨模态 STOP token：不同候选来自不同前缀。**后续观察可能为早期位置增加消歧信息；在最终时刻对候选与原落点共同重评，可能提供原旧表示之外的收益证据。** 这是待测机制，不能从“token 时间不同”直接断言表示无效或不可比较。

### 具体设计

已有接口已提供所需的低成本入口：DUET 最后一次 `nav_outs['gmap_embeds']` 是在当前完整已知图和同一条指令下得到的节点表示；`global_logits` 的 visited mask 仅屏蔽动作分数，没有删除这些节点 embedding。按 `gmap_vpids` 找到已观察候选 `v` 和原落点 `b`，直接读两个 node token，再由轻量联合头使用二者表示、其差值和已知几何预测相对收益。无需为每个候选另跑骨干，也无需先新增 Transformer。[固定版本 `vilmodel.py`，全局编码、动作 mask 与输出](https://github.com/cshizhe/VLN-DUET/blob/93e8b233164bc079a6db48b8a0a78d123ec8de41/map_nav_src/models/vilmodel.py#L749)

这些表示概括的是最终图状态，不等于保留完整原始时序或所有视觉细节。若训练机制面板切换指令，必须对同一非文本图输入重新执行该指令的语言条件编码，不能只改 instruction ID；也不能给早期节点补采未观察过的视角。最终图在停止时已经可得，不等于允许使用选定返回动作之后的新执行观察。

**共同上下文 Transformer 本身已被 Mind the Gap 覆盖。** 候选 B 的可保留主张只能是：对原策略候选与备选做同证据范围的比较，对 A 的相对净效用学习有可测增量，并且能解释这种增量来自后续证据。若仅换更大编码器就涨点，不能写成新机制。

### 分开检验表示与目标

| 输入表示 | 普通目标 BCE／固定选择规则 | 候选贡献 A 的相对效用监督 |
|---|---|---|
| E1 各访问时刻表示 | F0 | F1 |
| 同一最终历史重评 | G0 | G1 |

四组必须使用相同自然任务、候选集合、已观察视觉、训练预算及相近有效参数量。G0 是必要近邻，不能用 F0 作为唯一对照。

- `F1−F0` 和 `G1−G0` 检验执行收益目标。
- `G0−F0` 和 `G1−F1` 检验共同历史重评。
- 历史顺序/后续证据置换作为机制诊断，保持节点集合、几何、候选、当前点和返回路径成本固定；不得当作新的导航样本主结果。
- 旧表示加等容量 MLP、只增加几何、最终上下文中屏蔽后续观察应分别作为成本允许时的排除项。若表示收益来自更多参数或位置捷径，应停止“后续证据消歧”的解释。
- E1 输入为 STOP token，而这里读 node token，二者语义角色也不同。若要单独证明“信息过时”，需要再比较同一节点访问时的 node token 与最终 node token；只有 F0/G0 差异不能把收益全部归因于刷新时点。

**A 比 B 更适合作为当前主贡献候选。** B 先承担机制和结构改进；只有上述对照证明其独立增量，才考虑列为第二项贡献。用户需要的是能成立的小论文，不需要人为凑出两个新模块。

## 5. 应保留与应放弃的写法

可作为预研目标写：

> 研究固定导航策略结束后，如何依据完整已知历史和实际返回代价，学习相对原终点的选择性改写。通过自然轨迹内的候选收益监督与候选—基线证据比较，检验能否在保护原有成功的同时获得额外成功，并维持路径效率。

暂时不能写：首次解决停止、首次历史目标定位、首次风险感知导航、首次反事实策略改进、保证不伤害基线、低参数即新颖、已获得导航提升。

这一方向仍需三项闭环证据：训练房屋中存在可观的执行收益机会；方法优于同数据强对照；冻结后在完整未见场景、多种子及第二设置中得到一致收益。`val_unseen` 已用于 E1 开发观察，后续每次访问继续登记；任何新阈值、采样比例、损失或模型选择都先在按房屋划分的训练开发集完成，不能以反复查看验证集来替代方法验证。
