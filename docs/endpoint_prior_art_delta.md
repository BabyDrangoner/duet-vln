# 四格终点配对：针对性先行工作补核

日期：2026-10-03。先阅读了 [已有审计](prior_art_audit_20261003.md)和[候选说明](next_method_options.md)，本轮只补核下列四篇原文的方法与数据构造段落。未读取 E1 训练结果，未修改数据、损失、配置或协议。

## 结论

**历史终点定位、停止专项训练、共享视觉候选下的语言负例、指令/轨迹对比学习均已有直接先行工作。** 尤其 VLN-Trans 比“泛泛使用困难负例”更接近：它在同一候选视觉集合下构造不同正负子指令。因此，“固定视觉、只改变语言”不能单独作为本课题的新贡献。

本次核对的方法段落没有给出完整的联合构造：两条原始人类指令对应互斥几何目标，在逐时刻严格相同的非文本访问前缀上独立重算语言条件表示，并以两种实际访问顺序共同训练两个终点的偏好翻转。这是**有限范围内尚未核实到完整同构方法**，不是首创证明；冻结基座、小参数头和 softplus 也不补足该证明。

## 仍缺什么证据

1. **完整重复排查尚未闭合。** 未逐行复现四篇的数据生成器，也未穷尽相邻的语言条件视频定位、奖励建模及后续工作。论文定稿前仍需核对最接近公开实现与新版本；“未找到相同四格”不能升级为“首次”。
2. **四格不是天然的困难负例。** 互斥几何目标只保证标签相反。需要 E1 证明普通自然 BCE、已知增强 BCE 和同数据 BCE 不能同样解决任务；尚无 E1 结果，不能预先作此判断。
3. **不能把联合构造拆成若干已有词语后相加称创新。** 当前可检验的增量只有：C3 相对 C2 的数据价值，以及 M 相对完全同数据 C3 的目标价值。若没有增量，低参数实现或概念重命名不能补救结论。
4. **语义和部署边界继续有效。** 同列只共享该时刻的非文本前缀，两列并非同一个最终完整历史；两种顺序也未使所有前缀长度相同。目标 `<3 m` 不保证完整指令遵循。若成立的只是终点压力集辨别，仍须另行验证完整返回计费下的导航收益。

本次补核不建议改动已冻结试验。当前最稳妥的表述是“检验一种严格配对的终点监督数据构造及其增量”，而不是宣布发现了新的停止、对比学习或因果推理方法。
