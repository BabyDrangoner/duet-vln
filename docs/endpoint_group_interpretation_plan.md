# E1 四臂结果解释预案

记录日期：2026-10-03。**记录时尚无 E1 四臂训练结果，本文未查看 E1 结果。** 本文固定解释边界，不新增通过阈值、不更改训练或验证访问协议，也不认定方法新颖性。

依据：[训练协议](endpoint_training_protocol_draft.md)、四臂配置 [C1](../configs/endpoint_group_C1.json)、[C2](../configs/endpoint_group_C2.json)、[C3](../configs/endpoint_group_C3.json)、[M](../configs/endpoint_group_M.json)、[目标函数](../src/vln_improve/endpoint_group_objectives.py)及[分析器](../scripts/analyze_endpoint_group_results.py)。旧草案中的执行状态不作为当前完成证据；固定配置与已封存的数据、checkpoint 身份用于复核实际运行。

## 1. 这次实验检验什么

研究候选是：同一非文本观察前缀下，两条真实指令对不同历史终点的偏好，能否通过配对数据和显式排序监督学得更好。D3 已证明配对可构造、模拟器输入能严格匹配；这些是数据与工程证据，不是困难程度或方法收益。此前 S1 只证明已观察历史存在终点选择空间，没有建立动作候选数量导致 STOP 偏置的解释。

E1 使用同一冻结 DUET、同容量 `1536→128→ReLU→1` 头，共同 fit 512/dev 128 个原始 pair。四臂同 seed 的初始化、组顺序和 1280 次更新相同；主 checkpoint 固定第 20 epoch。C3/M 的数据逐项相同。C1/C2/C3 的真实状态数及采集成本可能不同，必须随结果公布，不能统称为全部预算相同。E0 的小样本工程结果不能替代 C1。

## 2. 固定差值的解释

分析始终同时报告 `C2−C1`、`C3−C2`、`M−C3`，不事后换参照组。

| 差值 | 若结果有利，可以支持 | 仍不能支持 |
|---|---|---|
| C2−C1 | 在共同原始任务池、固定小头和更新预算下，参考路径与越过目标增强这套数据方案比仅自然轨迹有增量。 | 首创越过目标增强；完整复现或击败 Mind the Gap；排除更多真实状态、不同长度或正负分布的作用。 |
| C3−C2 | 同一来源池中，双指令、双历史的配对数据方案比本版 C2 数据方案更有用。两者均用普通 BCE。 | 只由“指令困难负例”这一单一因素引起；已消除历史长度、覆盖范围及中间标签分布的差异。 |
| M−C3 | 在完全相同数据、初始化、容量及更新次数下，固定 `0.1×pair loss` 有增量。 | 数据构造本身有贡献；普通 BCE 不足以解决一般 VLN；softplus 公式具有新颖性；已经改善完整导航。 |

M 优于 C1 不能替代中间两个差值。若 C3 已达到 M 的表现，就不能把贡献归于 pair loss；若 C3 未显示相对 C2 的增量，就不能声称配对数据优于该已知增强控制。效果不确定应保留为不确定，不能将“未显示增量”写成严格等效或普遍无效。

## 3. 指标与信息边界

六项指标全部保留：自然/C2/配对面板 BCE、pair ranking loss、两个 order 的“两指令同时排序正确率”的均值、两个 order 全对的 pair 比例。差值统一为后者减前者；损失越低越好，正确率越高越好。同时看每场景支持和原始救回/损害计数，不只报净值。

- ranking loss 与 M 的训练目标直接一致；仅它下降，可能只是扩大已有正确排序的 margin。需结合严格排序正确率和其他面板解释，不能当成独立导航验证。
- 自然面板 BCE 衡量这些状态的几何目标分类损失。下降不直接等于 SR/SPL 提升，也不单独证明概率已经校准。
- “救回/损害”指 pair/order 的排序正确性变化，不是救回或损害了导航任务。
- 标签是原指令目标 `<3 m`，不是完整指令遵循。两个目标间隔大于 6 m 保证标签互斥，不证明强制历史完成了原指令的所有动作。
- 每个 feature 只含访问该节点时的前缀。两条指令在同一列共享非文本输入；不同目标列的前缀不同。不能写成“看完最终历史后重编码所有旧节点”。
- 两条指令都正确反转终点偏好，可反驳单纯位置分数加独立指令常数这一简单解释；仍不足以排除所有语言共现或场景捷径。

实际部署只重排**已观察历史终点**，保持原移动动作和在线 STOP；完整已走路径及返回路线全部计费。不能据此声称改善了探索、在线停止时机或未观察目标发现能力。工程 best-dev checkpoint 不替代固定 final。

## 4. 开发集、种子与区间

完整自然 `train_dev` 基线已达 SR 97.820069%、SPL 96.416810%，存在明显导航收益天花板。它与配对压力面板的难度不是一回事。官方基座训练已接触 R2R 训练房屋，`train_fit/train_dev` 只隔离适配器拟合，不能称为基座未见场景；原始任务还经过配对和 C2 可构造性筛选，结论先限于该子集。这是需披露的基础训练暴露，不能用“开发集留出”掩盖。

官方 `val_unseen` 已用作有限开发集，既有基线与诊断已产生暴露；官方基座代码本身也按该集 SPL 选择 checkpoint，作者精确日志未取得。后续导航运行和利用已有输出作新的分析，都须先登记。没有对其拟合梯度，不代表它是盲测；多轮访问后的提升不能描述为一次独立检验。本解释计划不增加任何验证访问额度。

- 预定训练 seed 0/1/2 衡量小头初始化和组顺序的不稳定性。进入三种子阶段后报告全部三次及均值/标准差，不能挑 seed；若按原协议止于 seed 0，如实写成单种子试验。
- 分析器每次只比较同一 seed 的四个 final。场景 bootstrap 固定 10000 次、随机种子 0，共享场景抽样，保留场景内完整 pair，按抽到的 pair 总数计算效应。它估计固定头在这些开发场景上的抽样不确定性，不能替代重新训练的种子不确定性。
- 四个 rollout 不是四个独立样本，同一 pair 的三个 seed 也不是三个新任务。场景数有限，95% 百分位区间需连同场景支持报告；当前区间未经多重比较校正。不能从六指标、三差值、三种子中挑一个有利区间定胜负。

## 5. 小论文仍缺的最低证据

E1 成功训练或某个压力面板指标变好，均不足以宣布论文贡献成立。至少还需要：

1. **机制增量与反例**：完整报告三固定差值、三面板代价、场景间差异和失败例；如需新增诊断，先固定问题与数据范围。不得为了得到有利结果重新筛 pair 或改标签。
2. **真正导航收益**：在另行登记的完整官方开发评估中，与冻结 DUET 和相同终点策略的强控制比较 SR、SPL及路径成本，保持在线轨迹不变并核对返回计费。机制面板提升而导航无提升时，结论限于机制面板。
3. **稳定性及更强普通控制**：按既定三种子协议核验；若推进到论文主张，补足协议提出的 C1-all 等强控制，公开更大自然数据预算，防止把自然 BCE 的数据不足包装为新目标的必要性。
4. **泛化和先行工作差异**：补充独立数据或另一基座的证据，并逐项说明与已知目标判别、越过目标增强、指令对比学习的区别。当前组合与低算力实现本身不构成新颖性证明。
5. **可复核的最终评估**：明确所有开发访问和成本。`test_unseen` 服务、账户与提交可用性仍待确认；只有方法冻结并审查具体产物后才考虑盲评。入口不可用时，保留局限，不能把已用于开发的 `val_unseen` 改称测试集。

以上列的是证据缺口，不是新增数值门槛。是否继续按原冻结协议和完整结果判读；负结果、取舍和协议修订均保留记录。
