# E2：学习何时值得改写导航终点

日期：2026-10-06。状态：失败诊断完成；新核心原型已实现，正式训练与导航收益尚未验证。

## 1. 决定

停止把 E1 的“双目标辨别更准”作为导航主故事。下一版研究问题是：

> 冻结导航器完成探索后，如何利用已经观察的历史，判断替换原终点能否获得实际净收益，同时避免破坏正确决定和无效回走？

这次修改涉及**训练样本单位、监督目标、表示接口和最终决策**。不继续围绕 E1 换 checkpoint 或调排序损失权重。旧结果全部保留。

该范围可以组织成一篇小论文的候选研究包，但贡献尚未成立。主贡献候选是一套可执行的终点干预学习方法；共同终止上下文只作为其中待消融的机制，不为凑数量另算一个新颖点。

## 2. 为什么要这样改

完整证据见 [失败诊断](e2_failure_diagnosis.md)。最有决策价值的事实是：

| 已核实的问题 | 证据 | 对设计的要求 |
| --- | --- | --- |
| 误改损害比救回收益昂贵 | M 救回 60 条，平均 SPL 0.476；误改坏 63 条，原平均 SPL 0.737 | 不能只优化成功节点分类准确率或救回数量 |
| 仍成功的任务也被多走路拖累 | 256 条仍成功却换点，其中 253 条返程更长；贡献 −1.089 pp SPL | 标签必须包含完整实际返程成本 |
| 候选中可能根本没有成功点 | 669 条原失败中 457 条没有成功历史观察 | 训练必须包含全候选失败和保留原决策 |
| 大部分下降发生在正常停止后 | 普通 STOP 的 2,281 条贡献 −1.842 pp SPL | 当前优先解决终点替换，不能把问题归给步数上限 |
| 一个基线置信阈值未必足够 | 救回/损害组原 STOP 概率均值约 0.644/0.631 | 同时利用语义、原决策证据和执行成本；阈值方法必须作强对照 |
| E1 自然样本覆盖有限 | 仅 1,024 条自然 fit 指令；配对强制历史更长且保证出现两个目标 | 扩大自然任务覆盖，不能只增加人工配对样本 |
| 正向干预监督极少 | 旧自然 fit 中 990/1,024 条已成功；仅 10 条有正 ΔSPL 候选，共 19 个候选 | 先补齐可恢复失败的训练支持，不能直接靠旧缓存训练新目标 |
| 训练代理指标有过拟合迹象 | M 训练 BCE 继续下降，公共 dev BCE 从 epoch 5 的 0.2624 升至 epoch 20 的 0.2744 | 预先固定由训练开发集选择 checkpoint 的规则 |

“跨时刻 STOP 表征不可比”和“强制历史导致迁移失败”还只是解释假设。本轮记录缺少 head logits 和对应 embedding，不能把它们写成已经证明的原因。

## 3. 方法：完整执行后的相对收益

### 3.1 一个训练样本是一整个决策历史

对历史 `H`，记录：实际观察过的候选集合、结束时位置 `x`、已经执行的前缀长度 `L`、DUET 原终点 `b`、各候选实际返回路线。

`KEEP` 的含义是保留 `b` **以及基线自己的返回路线**，不是直接留在当前位置。路过但没有实际观察的节点、未访问候选，不能加入终点集合。

在训练房屋内，为每个候选 `v` 构造：

```text
S(v) = 1[候选距离真实目标 < 3 m]
P(v) = S(v) × L_ref / max(L_ref, L + c_H(x,v), 0.01)
ΔSR(v;b)  = S(v) - S(b)
ΔSPL(v;b) = P(v) - P(b)
```

`c_H` 来自已发现图上真正执行的返回路线；`L_ref` 严格使用当前评估器的参考路径逐段距离累加。目标位置、目标距离、参考路径长度只进入标签和评测，不进入策略输入。

这样显式区分四种情况：原错新对、原对新错、两者都对但路程不同、两者都错。两者都错时，不能只因更靠近目标就给出成功收益；E1 的平均导航误差降低正说明它和 SR/SPL 不是同一目标。

### 3.2 联合比较候选和原决定

推理输入包含：

- 结束时 DUET 已计算的候选 global node token。
- 原终点 token、候选与原终点的表示差。
- 同一步的 global/local STOP 上下文。
- 原 STOP 概率、候选年龄、原终点身份、已走长度与发现图返回成本。

这些终止表示已经在同一图和指令下计算过，不需要对每个旧节点再次运行骨干。原型是 **362,370 参数**的小模型，输出两个预测收益。

当前工程原型仅在某候选预测 `ΔSR≥0` 且 `ΔSPL>0` 时考虑替换，选择预测 SPL 增益最大的唯一候选，否则保留原终点。原终点预测固定为零，零初始化时完全保留基线。

这是预测规则，**不保证真实指标不会下降**。选择阈值与任何后续校准只能由训练开发集确定；本轮没有在 `val_unseen` 上搜索阈值。

### 3.3 不把标签换名当创新

同一历史内减去常数 `P(b)` 不会改变候选的真实排序。因此，单独把绝对 SPL 标签改名为 ΔSPL 不能构成新算法。必须证明：

1. 同样的数据和输入下，原终点参照的联合比较确实优于普通绝对效用回归。
2. 完整执行收益监督优于目标概率加路径长度的便宜规则。
3. 如果宣称后续证据有用，必须排除更换 token 类型、更多参数和几何捷径。

原型先使用普通双输出 Smooth L1 回归。代码里的有害正收益惩罚默认关闭，仅保留为后续对照接口；不在结果出来前把它包装成第二个创新。

## 4. 论文贡献如何成立

### 主贡献候选：面向完整执行收益的终点干预学习

具体范围是：在冻结导航器的同一历史里，对**全部合法终点**解析计算真实返回后的效用，显式学习相对原决定的成功与效率变化，并保留原决定这一备选。

它与历史目标定位的差别在于学习“值得换吗”，而不只是“哪个点像目标”。它与探索阶段的干预强化学习不同：各候选的返回路线由同一发现图确定，训练终局指标再由训练标注和完整评测图计算，不需要为每个候选采集新的视觉未来。完整评测图和目标标注不进入推理。

但相对收益、选择性干预、保守策略改进本身都有先行工作。我们只检验上述具体终点问题中的方法价值，不使用“首次反事实学习”或“安全改进保证”等表述。

### 可选的第二贡献：共同终止证据确有独立作用

只有当控制了表示类型、维度、数据和目标后，最终上下文仍显著减少误改并提高净收益，才考虑把它作为第二项实证机制贡献。

最低机制对照应包含 **访问时 node token 与终止时同类 node token**。直接比较旧 STOP token 和新 node token 同时改变了时间与 token 语义，无法单独证明“旧证据过时”。共同历史重评已有先行工作，也不能直接作为架构首创。

最接近工作的事实与链接见 [本轮查新](e2_prior_art_check.md)：Mind the Gap 已覆盖完整历史重评和返回计费，SeekVLN 已覆盖相对不干预分支的收益训练。因此，本课题的增量必须由具体监督构造及强对照支撑。

## 5. 数据与训练：先补真实支持量

### 5.1 新缓存，不复用不含所需信息的旧向量

E1 缓存没有完整的终止 node token，不能直接改 schema 冒充 E2 数据。新缓存按 episode 保存：

- 原始自然轨迹、实际观察 ID、所有候选的发现图返回路线。
- 访问时 node token、访问时 STOP token、终止时 node/context token。
- 原 STOP 概率、原终点与所有允许的几何输入。
- 与输入分开的训练标签、参考路径长度和逐候选真实指标。
- 数据、骨干、代码、指令列表和采集配置 SHA。

全量原自然任务池为 `train_fit` 11,149 条、49 个场景；`train_dev` 2,890 条、12 个场景。先在训练房屋进行固定、按场景覆盖的采集试验，再完成原自然池。不能继续只挑容易构造双目标的任务。

旧自然 fit 的完整支持量审计已经完成：1,024 条中原成功 990 条（96.68%），失败 34 条，其中 10 条可以通过已观察历史救回，24 条没有成功候选。只有上述 10 条任务、19 个候选提供正 ΔSPL 标签。所有 1,024 条的原终点都在停止当前位置，因此原返程为零，“同样成功但返回更便宜”的替代候选为零是结构性结果。

这说明旧缓存能提供“不要无谓返回”的监督，却缺少正向替换的支持量；不能把大量重复这 10 条任务当作补齐证据。该池经过配对任务筛选，而且来自训练房屋，不能将 96.68% 推广为一般导航性能，也不能据此断言训练和验证差距的唯一原因。审计仅重放旧训练缓存，未执行新导航、训练更新或验证访问。见 [支持量报告](../outputs/study-20261006-e2/train-fit-intervention-support.json)。

新数据的第一张统计表仍须逐场景报告：原决策成功、可救回失败、无成功候选、双方成功但有成本差。正式训练前固定正收益独立任务数、场景覆盖及开发集支持量的最低要求；若仍不足，先解决采集覆盖，不用几乎全部 KEEP 冒充成功。

### 5.2 需要增强时，先固定其用途

优先保留自然历史的真实比例。若训练房屋的基座过强，正收益例过少，可在训练集单独固定一次合法动作扰动、再让冻结策略继续，采集偏离后的真实历史。扰动时刻和动作只由可观测信息与固定随机种子决定，不能按目标距离挑“有利错误”。

这属于已知的策略数据增强思路，所有学习对照必须共享数据。它不算新增创新；增强历史应单独标记，自然与增强结果分别报告。现有双指令配对可用于语言敏感性诊断，暂不继续给它默认 0.5 的训练权重。

先按原有场景和原始指令划分，再派生增强历史，防止同一任务的变体跨越 fit/dev。训练批次可以提高正收益任务的出现频率，但最终校准、选模和干预频率统计必须使用未经重采样的自然 `train_dev`；增强开发样本单独报告。所有对照共享重采样策略，避免收益实际来自不同数据预算。

增强的具体采样配置尚未固定：先完成训练侧支持量统计，再形成新的不可变采集配置；不使用验证结果挑增强比例。

### 5.3 训练与 checkpoint

先 seed 0 做开发，骨干完全冻结，缓存后仅训练小头。学习率、停止规则和 checkpoint 选择在首次 E2 验证前固定。

部署与选模围绕同一个目标：保护原有成功，并争取完整路径效率增益。当前部署原型约束预测 ΔSR，再最大化预测 ΔSPL；checkpoint 则用自然 `train_dev` 上实际完整候选选择与真实返回计费进行检查，预测值不能代替实际指标。

初版 checkpoint 规则预定为：先保留实际 SR 和 SPL 均不低于原基线的 checkpoint，再按 SR 优先、SPL 次之选择；若没有满足者，记录训练侧未通过并调整设计。完全等于 KEEP 基线也不能当作研究成功。所有学习对照使用同一规则，不按配对 BCE 最低选“导航最佳”。正式训练配置还须固定监测间隔和最大更新数，再开始训练；任何规则修订都记录在首次 E2 验证之前。

继续使用既有 CheckpointStore：模型、优化器、RNG、数据游标、历史一起保存；同步验证 Drive 后再清理本地旧副本；best 与 latest 分开保留。下一版正式 trainer 的完整恢复验收是上线条件，工程小步 smoke 不能替代它。

## 6. 强对照与验证顺序

全部先在相同训练开发缓存上比较，初期不重复跑官方验证：

| 对照 | 要排除的解释 |
| --- | --- |
| 原 DUET | 是否有实际导航提升 |
| 同输入、同容量 BCE + 保留规则 | 普通目标分类是否已经足够 |
| BCE 概率 / 完整可执行路径长度；另有固定距离惩罚 | 收益是否只是几何后处理 |
| 同输入、同容量绝对 SR/SPL 效用预测，再减预测原终点值 | 减去参照标签是否只是换名字 |
| 仅原 STOP、年龄和几何的收益模型 | 是否存在语言视觉之外的简单解释 |
| 完整 E2 | 联合原终点参照比较是否仍有额外价值 |
| 同类访问时 node token 替换终止 node token | 共同最终证据是否有独立作用 |

绝对效用对照预测每点的 SR/SPL，再减去同一模型预测的原终点 SR/SPL，使用与 E2 **完全相同**的非负 SR 筛选、正 SPL 筛选、KEEP 和并列处理。另列纯绝对 argmax 结果只能作为补充，不能替代这个匹配对照。

参数量、训练任务、候选集合、更新预算和调参次数要匹配；无法完全相同的差别明确报告。目标是让强便宜对照尽可能有竞争力。

若训练侧支持不足、E2 达不到绝对效用/概率长度控制的表现，或收益仅来自几何，则停止相应创新主张并改设计。不能为了维持故事删掉强对照。

训练侧形成稳定方案后，再锁定最多 **5 个 E2 seed-0 变体**、每个一次完整 `val_unseen`。既有 pilot 已用 5/12 变体，这一计划在原预算内；本页是研究顺序，不是已登记的评测配置。真正执行前固定每个配置、checkpoint、源码和全部比较，逐项登记。之后才考虑 seed 0/1/2 与第二基座/数据设置；官方 `test` 留到方法冻结后。
